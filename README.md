# AI Evals Quest

A dependency-free static learning game for a six-week AI Evals curriculum.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Curriculum
1. Foundations & error analysis
2. Reliable LLM judges
3. Safety & adversarial testing
4. RAG evaluation
5. Multi-agent & tool evaluation
6. Production eval infrastructure

Each week contains four lessons, practical missions, instructor challenges, source links, and a three-question checkpoint. Lessons award 25 XP; passing a checkpoint awards a badge and 100 XP.

Progress autosaves in browser localStorage. Use Export/Import to transfer progress between browsers or devices. Automatic cross-device sync requires authentication and a backend/database.

## Deploy
GitHub Actions deploys the repository root to GitHub Pages on pushes to `main`. In repository Settings → Pages, set Build and deployment source to **GitHub Actions** if it is not already selected.

## Resource policy
Resources prioritize primary documentation and research. Vendor documentation is vendor-authored guidance, not independent validation. Links may change and should be periodically rechecked. OpenAI's legacy Evals API is deprecated; use current evaluation workflows for new projects.
